
# Frontend Progress — AI Study Notes Assistant

## Status
- React + Vite berhasil dijalankan di localhost.
- Tampilan UI sudah muncul.
- Tombol UI sudah berfungsi sesuai harapan.

## Materi yang sudah dipelajari
- `useState`: menyimpan dan memperbarui state.
- `setTitle` dan `setContent`: memperbarui judul dan isi editor.
- `selectNote`: mengisi editor berdasarkan catatan yang dipilih.
- `onChange`: menangani perubahan input.
- Penghitungan jumlah kata dari state `content`.

## Catatan penting
- Frontend saat ini menggunakan data contoh.
- Perubahan catatan belum tersimpan ke database melalui API.
- Respons AI masih berupa simulasi.
- Backend FastAPI dan SQLite sudah tersedia dari tahap sebelumnya.

## Sesi berikutnya
1. Memahami `setNotes` dan fungsi `createNote`.
2. Memahami alur membuat serta memperbarui catatan.
3. Menghubungkan React dengan endpoint FastAPI.
4. Mengintegrasikan fitur Summary dan Q&A dengan backend.
